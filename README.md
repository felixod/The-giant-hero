# The-giant-hero

## Хранимая процедура sp_psee_ppc

Хранимая процедура разработана в среде Microsoft SQL Server Management Studio 14.0.17230.0, СУБД - MS SQL Server 2012.

**Местоположение:** сервер – minesrv, база – MSCADA.

**Учетные записи, которым разрешен вызов процедуры:** tu_ugmk1, tu_ugmk2.

**Наименование хранимой процедуры:** sp_psee_ppc

### Входные параметры:
- @days – глубина шага дней (по умолчанию 4 дня);
- @dt – дата от которой ведется отсчет шагов в глубину (по умолчанию текущая дата).

### Результат:
- Метка даты (date)
- Метка времени (datetime)
- Численное значение (float)
- Размерность (varchar)
- Наименование (varchar)
- Признак обработки (varchar)

### Пример вызова процедуры:
```sql
-- Вызов с параметрами по умолчанию (4 дня от текущей даты)
EXEC sp_psee_ppc;

-- Вызов с указанием 7 дней от текущей даты
EXEC sp_psee_ppc @days = 7;

-- Вызов с указанием конкретной даты и глубины
EXEC sp_psee_ppc @days = 10, @dt = '2023-01-01';
```

Файл с исходным кодом процедуры находится в `/workspace/sp_psee_ppc.sql`.
